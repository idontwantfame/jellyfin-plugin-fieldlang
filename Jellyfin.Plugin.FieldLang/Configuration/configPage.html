Required. Jellyfin's built-in TMDb key is compiled into the server assembly and cannot be reached from a plugin, so this plugin needs its own. A free v3 key works — register at themoviedb.org/signup, then copy the API Read Access v3 key from Settings → API. Nothing is sent anywhere except TMDb.
Rules are applied by the Apply per-field metadata languages scheduled task, which runs daily by default. Run it from Dashboard → Scheduled Tasks to apply changes immediately, or add triggers there to run it more often.

Rules

Leave a language blank to leave that field alone — the plugin only touches fields you give a language. Use an ISO 639-1 code, optionally region-qualified: tr, en, de, pt-BR. If TMDb has no data for a field in the language you pick, the existing value is kept rather than blanked.

Lock pins that one field so the normal metadata provider stops overwriting it. Unlocked, the provider rewrites it on every refresh and this plugin puts it back on the next run — still correct, but the wrong language is visible in between. Tagline has no lock in Jellyfin, so it always works the second way.

Original title is different: enable its checkbox instead of entering a language. For each movie or series Field Language uses Jellyfin's populated OriginalTitle, falling back to TMDb's original title/name. It changes the server title seen by all clients, preserves an explicit sort title, and stops managing an item if it later detects a manual title edit. It replaces the fixed-language Title rule and always locks the title. Existing manual title locks are skipped. Saving this rule does not authorize any changes; review a dry-run and approve samples or libraries below.

Original-title safety tools

Save the rule first, then run a dry-run before the scheduled task. It makes no metadata changes and lists the current server title, proposed title, and source. Rollback restores only titles still owned by Field Language; later manual edits are skipped.
