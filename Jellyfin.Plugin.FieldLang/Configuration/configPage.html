Required. The server's built-in TMDb key is compiled into the core assembly and cannot be reached from a plugin, so this plugin needs its own. A free v3 key from themoviedb.org works.
Pins each applied field so the normal metadata provider stops overwriting it. With this off, the provider rewrites the field on every refresh and this plugin puts it back afterwards — still correct, but the wrong language is briefly visible. Tagline has no lock in Jellyfin and always relies on re-application.
Applies rules immediately when an item is added or refreshed. With this off, only the scheduled task applies them.

Rules

Leave a language blank to leave that field alone — the plugin only touches fields you give a language. Use an ISO 639-1 code, optionally region-qualified: tr, en, de, pt-BR. If TMDb has no data for a field in the language you pick, the existing value is kept rather than blanked.
